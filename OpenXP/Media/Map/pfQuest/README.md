# pfQuest objective icons

`slay_mono.tga`, `loot_mono.tga` and `object_mono.tga` are by Eric Mauser
(Shagu), from pfQuest (https://github.com/shagu/pfQuest), under the MIT
license in `LICENSE.txt`. Copied from Questie's `Icons` folder, where
Questie's `Icons/LICENSE.md` lists them as pfQuest's MIT-licensed files.
OpenXP tints them in game for kill, loot and use/talk objectives
(Nav/Pins.lua).
